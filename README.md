# El Guerrero Dragon - PC1 JavaScript Avanzado

One Page estatica para el chifa ficticio **El Guerrero Dragon**.

## Stack

- HTML5
- CSS3
- JavaScript vanilla

## Funcionalidades PC1

1. Formulario para planear una visita.
2. Procesamiento y mensaje personalizado con interpolacion.
3. Filtro de carta por categoria.
4. Buscador de platos.
5. Explorador interactivo de Los 5 Furiosos.
6. Contador de comensales con recomendacion.
7. Galeria interactiva.
8. Navegacion dinamica por secciones.
9. Copiar telefono de contacto.
10. Barra de notificaciones aleatorias.

## Estructura

```text
dist/
├── index.html
├── css/
│   └── styles.css
└── js/
    └── main.js
```

La logica principal se mantiene en `main.js` para que sea facil de revisar durante la evaluacion.
